# Artifact Generation Skill

## Workflow
1. Determine requested format and delivery surface.
2. Gather all required content and assets.
3. Build the artifact with appropriate structure and styling.
4. Validate format and semantics.
5. Re-open/render when practical.
6. Fix defects.
7. Confirm exact path before sharing.

## Quality checks
- no clipped or missing content;
- correct headings/tables/formulas;
- working links where expected;
- consistent naming;
- correct page/slide/sheet structure;
- no unintended metadata or secrets.

## Delivery
Link only to files that exist in the active runtime and have been validated.
