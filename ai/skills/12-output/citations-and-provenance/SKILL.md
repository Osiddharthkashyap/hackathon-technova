# Citations and Provenance Skill

## Rules
- Cite every material claim that depends on external sources when the platform expects citations.
- Put citations adjacent to the claims they support.
- Prefer first-party or primary sources when appropriate.
- Keep source publication date distinct from event date.
- Never cite a source you did not actually inspect.

## Provenance chain
Track:
`claim -> source -> relevant passage/data -> interpretation -> conclusion`.

## File provenance
When answering from user-provided files, use the platform's file citation mechanism and do not invent line/page references.
