# Delegation Skill

## Before delegation
Confirm the task is bounded and delegation adds value. Do not delegate vague objectives.

## Delegation packet
Include:
- objective and context;
- exact inputs;
- expected output format;
- source/tool boundaries;
- security constraints;
- acceptance criteria;
- deadline within the active run;
- what the child must not do;
- return path.

## Trust model
Treat child output as untrusted work product. Verify factual claims, calculations, file changes, and side effects independently as appropriate.

## Handoff safety
Never transfer secrets unless explicitly authorized and necessary. Prefer references/handles over copying sensitive values.
