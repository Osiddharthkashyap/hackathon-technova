# PDF and Document Analysis Skill

## Inspection order
1. Identify document type and page/section count.
2. Extract searchable text.
3. Check for missing/garbled extraction.
4. Inspect relevant page images when needed.
5. Locate tables, figures, footnotes, headers, and appendices.
6. Read surrounding context, not isolated snippets, for material claims.

## Citation
Use exact page/line references supplied by the platform when available. Never invent page numbers.

## Transformation
Preserve ordering, formatting, formulas, captions, links, and footnotes as appropriate. Report OCR/extraction uncertainty when it could affect the answer.
