# Decision Analysis Skill

## Method
1. Define the decision and candidate options.
2. Extract user-specified criteria.
3. Collect comparable evidence.
4. Separate objective properties from value judgments.
5. Explain trade-offs and scenario sensitivity.
6. Let the user choose unless the task authorizes an explicit optimization criterion.

## Rules
- Do not smuggle in criteria the user did not request when they could change the outcome.
- Do not present uncertain claims as established.
- For sensitive civic/political decisions, provide neutral evidence and comparisons rather than endorsing a choice.
